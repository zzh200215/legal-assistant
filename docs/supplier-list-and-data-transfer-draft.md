## 2. 数据出境说明

### 2.1 结论（草案）

**当前主链路（LLM 调用）不发生数据出境**：

- 大模型供应商为阿里云百炼 dashscope，API 端点 `https://dashscope.aliyuncs.com/compatible-mode/v1`，服务器位于**中国大陆境内**；
- 嵌入模型 text-embedding-v3 同为 dashscope 境内服务；
- 向量检索、数据库、缓存均在境内部署。

### 2.2 出境风险点（需部署方/法务确认）

| 场景 | 是否存在出境 | 说明 |
|---|---|---|
| LLM 调用 dashscope | 否 | 境内机房；出站前已执行 PII 脱敏 |
| Ollama 本地模型 | 否 | 数据不出本地 |
| SMTP 企业邮箱 | 视部署方选择 | 若选用境外邮件服务商则涉及邮件内容出境 |
| Stripe 在线支付 | 是（未启用） | 试点默认关闭；开通前需单独评估并取得同意 |
| 电子签名（法大大/上上签） | 视服务商 | 沙箱阶段，未启用 |
| 云厂商（阿里云）境内机房 | 否 | 属境内处理 |

### 2.3 供应商数据处理责任

- 供应商仅按服务目的处理数据，我们已通过服务协议约束其不得将数据传输至其他目的地、不得用于模型训练披露敏感信息；
- dashscope 侧的"请求不落盘 / 不用于训练"承诺需在正式商用前取得**书面确认**【法务确认】，见 SLA §4.5；
- 若未来切换境外 LLM 供应商或启用 Stripe，将触发《个人信息保护法》数据出境合规评估，并更新本清单与隐私政策。
