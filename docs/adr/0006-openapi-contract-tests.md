# ADR-0006：契约门测试保护 OpenAPI

- **状态**：已采纳
- **日期**：2026

## 背景

重构阶段会移动路由、合并子路由、下沉业务逻辑，存在接口契约漂移风险。

## 决策

以 OpenAPI 契约快照（`scripts/check_openapi_contract.py`）与前后端路由交叉比对
（`scripts/check_frontend_backend_contract.py`）作为契约门，重构不手写接口文档，
以自动生成的 OpenAPI 为准。

## 理由

- 路由重构（拆分/合并）容易无意改变路径或响应，快照比对可即时发现漂移。
- 前后端路由交叉比对能捕获前端调用指向已改名/删除路由的 404 级漂移。

## 后果

- 有意变更接口时必须同步更新契约快照。
- 重构期间任何路由路径/前缀调整都需通过契约门。
