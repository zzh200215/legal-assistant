> 用途：等保二级自评（docs/etc-protection-poc-self-assessment.md §2.7）差距项"安全负责人任命文件待成文"的成文交付物。

## 1. 任命

经平台管理层批准，现任命 **【姓名，待管理确认】** 为律智检 SaaS 平台信息安全负责人（下称"安全负责人"）。

- 任命生效日期：**【YYYY-MM-DD，待填写】**
- 任命任期：**【1 年 / 长期，待填写】**，可连任；重大组织调整时重新任命。
- 安全负责人不得同时担任平台系统管理岗（角色分离要求，见 §3）。

## 2. 职责

| # | 职责 | 对应制度/机制 |
|---|---|---|
| 1 | 牵头制定并维护安全管理制度与合规材料 | security-policy-compilation-draft.md、compliance-dossier.md |
| 2 | 监督平台安全运营与日志审计，处置安全事件 | 双轨日志（admin_audit_logs + operation_logs）、/api/admin/logs/search 集中检索 |
| 3 | 组织备份恢复演练与容灾预案验证 | celery beat 每日备份 + dr-drill-record.md |
| 4 | 组织漏洞扫描与渗透测试，跟踪整改闭环 | 漏洞扫描周期制度（security-policy-compilation-draft.md §新增） |

| 6 | 组织全员安全意识培训（每半年一次） | 制度汇编 §12 |
| 7 | 审批敏感数据对外提供、供应商数据处理 | 供应商清单 + 数据出境说明 |

## 3. 权限与资源

- 授予：安全审计日志只读查询、安全事件处置、合规材料维护、漏洞整改推进的协调权。
- 分离要求：不得授予系统管理（含用户账号增删改、密钥轮换）与审计管理（日志删除/修改）单一权限，防止职责冲突（三权分立）。

## 4. 报告线

- 安全负责人直接向平台管理层汇报；重大安全事件在应急预案要求时限内直接上报管理层。
- 每季度向管理层提交安全运营简报（扫描结果、事件、整改闭环）。
