# 云侧基线加固核查清单（草案）# 合规 5.3 交付

> 用途：等保二级自评差距项 #4（docs/etc-protection-poc-self-assessment.md §3 #4）的部署侧交付物。
> 范围：律智检 SaaS 生产部署在阿里云中国大陆机房的基线核查项；由部署方在正式商用前逐项核对。
> 现状：POC 阶段依赖云服务商默认基线 + 应用侧已有防护（HTTPS/JWT/OTP/加密/审计）；下表为正式部署前加固项。

## 1. 网络边界（安全组 / VPC）

| # | 核查项 | 说明 |
|---|---|---|
| 1.1 | 安全组最小化放行 | 仅开放 80/443（+ 运维 SSH 来源白名单），DB/Redis 不对公网开放 |
| 1.2 | VPC 隔离 | 应用 / 数据库 / 缓存分属不同子网，数据库仅允许应用网段访问 |
| 1.3 | Web 层防护 | 启用 WAF（或至少 CDN + HTTPS）；封禁常见攻击签名 |
| 1.4 | 访问控制 | RAM 子账号 + 最小权限；禁用 root 长期密钥 |

## 2. 计算与系统基线

| # | 核查项 | 说明 |
|---|---|---|
| 2.1 | 系统补丁 | 定期 yum/apt 安全更新；每月核查 |
| 2.2 | 主机加固 | 禁用多余服务；SSH 密钥登录（禁密码）；fail2ban 可选 |
| 2.3 | 安全镜像 | 使用官方/加固镜像，基线核查（等保镜像基线） |
| 2.4 | 杀毒/HIDS | 云服务器安全组件（云安全中心）开启，配置告警 |

## 3. 数据面（RDS / Redis / 对象存储）

| # | 核查项 | 说明 |
|---|---|---|
| 3.1 | RDS 备份 | 开启自动备份（≥每日）；备份异地（同城/异地容灾可选） |
| 3.2 | RDS 加密 | 磁盘加密（KMS）；连接使用 TLS；账号最小权限、不共用 |
| 3.3 | Redis 加固 | 仅内网访问；requirepass 开启；禁用危险命令 |
| 3.4 | 对象存储 | 私有读写（非公开）；bucket 权限最小化；开启服务端加密 |
| 3.5 | 密钥管理 | 加密密钥存 KMS/密钥管理，不入代码与环境变量明文 |

## 4. 日志与监控

| # | 核查项 | 说明 |
|---|---|---|
| 4.1 | 云侧日志 | 开启操作审计（ActionTrail）、SLS 日志服务采集应用日志 |
| 4.2 | 结构化日志 | 应用侧 STRUCTURED_LOG_JSON_LINES=True，JSON 行接入 SLS/自建 SIEM |
| 4.3 | 监控告警 | 云监控 CPU/内存/磁盘/带宽告警；对接 ALERT_WEBHOOK_URL |
| 4.4 | 日志留存 | 与 SLA 对齐（180 天活跃 + 归档 2 年） |

## 5. 账号与访问管理

| # | 核查项 | 说明 |
|---|---|---|
| 5.1 | 双重验证 | 云控制台开启 MFA |
| 5.2 | 密钥轮换 | 云 AK/SK 定期轮换；应用密钥按配置机制轮换 |
| 5.3 | 供应商凭据 | dashscope/邮件/支付等第三方密钥集中管理，最小化暴露 |

## 6. 核查执行方式

- 执行：部署方按上表逐项核对，勾选 + 截图留档；
- 频率：正式商用前一次全量；此后每半年复核一次【管理确认】；
- 记录：核查结果登记到等保自评 §4 POC 审计应对口径。
