试用期与违法解除赔偿咨询

委托人 张三 · 相对方 某科技有限公司 · 承办 张明律师

咨询
我与公司签了三年固定期限合同，约定试用期六个月。实际做了八个月才被辞退，公司说我"试用期考核不合格"。请问试用期最长可以多久？被辞退我能不能要求经济补偿？
结论

公司以"试用期考核不合格"解除的理由不成立，可以按经济补偿标准的二倍主张赔偿金。1

其一，三年以上固定期限劳动合同，试用期不得超过六个月；你在职八个月，已超过约定试用期，公司不能再以"试用期考核不合格"为由解除。1

其二，用人单位违法解除劳动合同的，应按经济补偿标准的二倍向劳动者支付赔偿金。2

其三，经济补偿按工作年限计算，每满一年支付一个月工资；六个月以上不满一年的按一年计，不满六个月的支付半个月工资。3
