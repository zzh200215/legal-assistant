01　做了什么

01

常驻 copilot 面板

每个页面右侧固定助手，可收起；工作台 / 案件「打开助手」直接开它，「整页」保留深度视图。栅格 248px / 1fr / 380px，收起 52px，面板按需加载、首屏无布局位移。

02

四层可信体验

咨询走 WS 真流式：检索法源 → 生成建议 → 抽取事实 → 核验引用逐步推送；证据卡展示条文原文、版本与效力；点任意一句高亮支撑它的证据；答案返回后由判官补判忠实度。

03

证据可核验性

生成时就算好四档徽标（引用已逐条核对 / 部分核对 / 待核 / 未引用），落库并接入管理员趋势、法源引用榜与语料缺口清单；历史记录回填标注「事后重算」，不假装是生成时结论。

04

三层评审

规则层 35 题 hit@5 / 引用准确率 / 拒答准确率全 1.0 → 跨模型裁判 glm-5.2 × qwen-plus 忠实度 31/31 → 人工抽检 25 条一致率 0.88；三层都是可重跑脚本，不是一次性报告。

05

法源语料与条号核验

引用不是装饰：把「有没有法源」推进到「条号对不对」，逐条核验版本与效力并给出四档徽标；历史记录回填标注「事后重算」，缺口进管理员语料清单。已覆盖 4 部法全文，按真实引用缺口再补，不堆条数。

06

工程质量与性能

入口 JS 114.8 → 84.2 KB（−27%），总资产 1689.1/1700；前端单测 120 / 任务与通知 e2e 21；后端全量 2679 passed，376 条 API、123 个迁移；定位并修掉 LLM 网关连接池跨事件循环复用根因，真机降级 5/24 → 0/10。
