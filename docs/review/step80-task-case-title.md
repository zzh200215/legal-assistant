## 1. 为什么补

step79 接通了 `case_id`，但任务列表只显示案件 id：

- 看板上只有一个数字，不知道是哪个案件；
- 表格没有案件列；
- 用户从案件工作台进来，仍要靠记忆确认。

## 2. 后端

`_attach_case_titles(db, payloads)`：

- 收集本页所有 `case_id`；
- 一次 `SELECT legal_cases.id, title WHERE id IN (...)`；
- 回填 `case_title`，没有案件时 `None`；
- 列表/子任务批量补，创建/详情/更新单条补。

`TaskOut` 增加 `case_title`（不写库，纯读时派生）。

## 3. 前端

- 看板任务卡：`case_title` 作为 accent 标签显示；
- 表格新增「案件」列，空值显示 `—`；
- 案件过滤 chip 保持不变。

## 6. 边界

1. **case_title 是读时派生**：不写库，案件改名后任务列表立即跟着变。
2. **只补当前页**：分页列表按当前页案件 id 批量查，不会拉全量案件。
3. **已删案件**：`case_id` 仍存在但查不到标题时返回 null，前端不显示。
4. **无案件任务**：文档/聊天/历史任务没有 case_id，不显示案件标签。
5. **表格列宽固定 150px**：长案件名省略，hover 显示 tooltip。
6. **看板只显示标题**：不额外显示案件 id。
7. **无权限变化**：仍按任务可见性 + 案件过滤，不因显示标题放宽。
8. **无迁移/新接口**：纯读时补字段。
