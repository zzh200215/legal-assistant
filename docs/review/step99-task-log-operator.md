## 5. 边界

1. **历史日志没有操作人**：迁移前日志 `user_id=NULL`，统一显示「系统」，无法回填。
2. **用户删除/改名**：按当前用户表实时取名；用户被删则显示「系统」或 `用户 id`；改名会改历史显示。
3. **日志无分页/筛选**：仍全量返回（现有上限），数据量大时需分页。
4. **评论仍无编辑/删除**，也不做敏感信息脱敏。
5. **操作人只到用户级**：没有部门/角色快照；跨组织共享任务按当前用户信息显示。
6. **批量操作日志只记操作人**：不记录逐条 skipped 原因。
7. **包体 +0.1 KB**：操作人列与评论元信息。
