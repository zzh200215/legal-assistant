## 1. 统计口径

`GET /tasks/` 的 `stats` 新增：

| 字段 | 口径 |
| --- | --- |
| `participating` | 我创建的 + 指派给我的 + 我作为协作者的 |
| `shared` | 部门/组织共享，排除我创建/负责/参与 |

- 统计在 `q` 上做 COUNT，与当前筛选一致、不分页；
- 使用 `EXISTS(task_collaborators)`，不加载全量任务；
- 与 `scope=participating` 列表口径一致。

## 2. 前端

- 统计区从 4 卡变 5 卡：总数 / 进行中 / 已逾期 / 共享任务 / 我参与的；
- 卡片可点击筛选，再次点击取消；与共享卡互斥（同属 scope 维度）；
- 参与数优先用服务端 `stats.participating`，旧接口缺失时按当前页兜底；
- 桌面五列、≤1100px 收成一列；
- 空状态文案补充「我参与的」条件。

## 5. 边界

1. **参与数随筛选变化**：统计在 `q` 上算，选「进行中」后参与数只算进行中，不是全量参与数。
2. **只有真实关联算参与**：历史文本协作者不算。
3. **协作者仍不收通知**：参与统计不等于提醒订阅。
4. **五卡在窄屏纵向排列**：没有横向滚动或折叠。
5. **共享/参与互斥**：同属 scope，不能叠加。
6. **包体 +0.9 KB**：第五卡与五列布局。
