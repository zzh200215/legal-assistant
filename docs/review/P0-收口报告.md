### 发现并修复的历史迁移 bug

`20260812_0074` 的 JSON 回填直接查询当前 ORM 模型，模型后来新增了 `review_due_at` 等列；在只建到 0074 的空库上会报 `Unknown column`，导致**全新 MySQL 无法从零升级**。

修复：回填前先用原始 SQL 统计旧表行数，空库直接跳过回填；同时兼容 Alembic `Connection` 与测试直接传入的 `Engine`。既有数据库已有数据时仍按原逻辑回填，开发库不受影响。
