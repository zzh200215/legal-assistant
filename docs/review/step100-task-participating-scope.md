## 1. 口径

| scope | 包含 |
| --- | --- |
| `all` | 所有可见任务 |
| `mine` | 我创建的 + 指派给我的 |
| `participating` | 我创建的 + 指派给我的 + 我作为协作者的 |
| `shared` | 部门/组织共享，排除我创建、我负责、我参与的任务 |

- 列表分页走 SQL `EXISTS(task_collaborators)`，不加载全部任务；
- `list_visible` 内存路径同步支持，避免两套口径分叉；
- 共享统计随 `shared` 口径排除协作者任务。

## 2. 前端

- 共享卡兜底计算同步排除「我参与」；

## 5. 边界

1. **只是列表筛选**：没有「我参与的」独立统计卡/计数；统计仍只有总数/进行中/逾期/共享。
2. **协作者仍不收通知**：参与范围不等于提醒订阅。
3. **共享口径变化**：`shared` 现在排除我作为协作者的任务；依赖旧口径的调用方需注意。
4. **只按当前用户**：不能按「某位协作者」筛选。
5. **历史文本协作者不参与**：只有真实 `task_collaborators` 关联才算。
6. **部门/组织共享口径不变**：仍按 task 的 department/org 字段。
7. **包体 +0.2 KB**：下拉选项与标签文案。
