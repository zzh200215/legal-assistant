## 2. POC 客户实测输入项（试点启动后收集）

1. 客户打开链接的**首次加载时长**与失败率（移动网络下）
2. 客户是否理解「令牌链接」（还是期望账号密码）
3. 律师最常发客户的内容：进度？文书？账单？（决定交付物优先级）
4. 客户是否二次打开链接（留存信号；portal_access_logs 可测）

## 4. 验收口径（正式版定义）

1. 客户侧页面可独立访问（不依赖管理端登录），链接鉴权全部通过 portal OTP 体系
2. 文书/PDF 下载走链接内鉴权，不暴露存储路径
3. 移动端可用（iPhone/Android 主流浏览器）
4. 访问数据可进周报（周报脚本增加 portal 指标）
