# 技术 Demo 流（M-2 配套）

配套：运营话术/问卷见 `pilot-success-playbook.md`；环境与账号见 `pilot-runbook.md`。
本文件给出 30 秒 Demo 的具体操作路径与预期，保证销售/客户成功同事照着走一遍即可开讲。

---

## 0. 准备（5 分钟）

- 环境：试点环境（或 staging），确认 `/api/health/ready` 200。
- 账号：预先创建的演示律师账号（试点账号 pilot01-lawyer / Pilot@2026，非管理员角色）。
- 素材：一个已建案件 + 一段真实脱敏合同文本（100-500 字）。
- 浏览器：Chrome 桌面端，全屏。

## 1. 法律咨询（10s）

1. 打开 `/legal-onboarding`（登录后默认落地页），选「独立律师」，点「进入工作台 →」。
2. 工作台切到「法律咨询」tab，输入：
   > 公司辞退我，工作 3 年，没给经济补偿金
3. 预期输出：分类=劳动争议；风险等级；置信度数字；引用列表（标题+条款+效力状态）；待补充事实。
4. 讲点：「每个结论都能点开核对法条原文和效力状态，不是空口结论。」

## 2. 提交律师审核（10s）

1. 点「提交律师审核」→ 状态变「待律师审核」。
2. 用 pilotXX-lawyer（dept_admin）账号打开「律师审核」tab，执行「通过」并留批注。
3. 讲点：「高风险自动进人工审核，AI 只做辅助，律师把关。」

## 3. 文书 + 交付（10s）

1. 回到案件 → 点「生成文书」→ 选「劳动争议仲裁申请书」（按咨询分类预选）。
2. 缺失字段显示【待补充】；导出 DOCX（或演示客户门户交付）。
3. 收尾：「您今天的审核结论会沉淀成评测用例，这套系统越用越准。」

---

## 备用场景（合同审查，30s）

1. 「合同审查」tab → 粘贴准备好的合同文本 → 提交。
2. 预期：风险条款列表（类型/等级/原文摘录/修改建议）+ 摘要 + 免责声明 + 参考依据（可点击核对）。
3. 讲点：逐条风险带原文出处，可回溯核对。

## 避坑清单

- 不要现场输入长合同（LLM 返回 2-5s，讲稿节奏会断）；用准备好的 100-500 字文本。
- 演示账号用试点律师账号，不要用管理员（看不到角色收敛后的真实律师界面）。
- 不演示支付/电子签署/开放 API（试点开关关闭）。
- LLM 偶发失败时会走确定性兜底，仍会出结果，但强调"这是降级模式"。
